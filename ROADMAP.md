# Roadmap and release gates

No stable release is declared by this setup. Complete and record these gates before a release:

- Compile the storage candidate in the complete Rust/kernel tree.
- Review missing UUID and refused-create validation.
- Obtain consented redacted evidence for firmware 15.3.1.
- Qualify reboot persistence before an installation guide.

Each gate needs a reproducible test or a reviewable evidence record. GitHub issues track the work; a linked GitHub Project groups the backlog when Projects authorization is available.
